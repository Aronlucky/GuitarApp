# Гитарный помощник

Устанавливаемое веб-приложение (PWA) для игры на гитаре. Вся логика — в одном файле `index.html`.

- **Метроном** — 30–250 BPM, размеры 2/4…7/8, деление доли, акцент, тап-темп.
- **Тюнер** — через микрофон, авто-определение струны, стрелка в центах, эталонные звуки, калибровка A4.
- **Песни** — Wonderwall (Oasis) и 505 (Arctic Monkeys): аккорды над текстом, табы, бой, аппликатуры.
- **Режим игры** — аккорды, бой и строки подсвечиваются синхронно с темпом; озвучка гитарой и метрономом,
  замедление темпа, а также игра под свою аудиозапись песни с синхронизацией.

Тексты песен защищены авторским правом и не встроены — их можно вписать в редакторе (✎) в формате
`[Em7]слова [G]продолжение`; сохраняются локально на устройстве.

## Запуск и установка

Микрофон и установка требуют https. Проще всего включить GitHub Pages
(Settings → Pages → ветка с этими файлами) и открыть страницу на телефоне:
Chrome/Android — «Установить приложение», Safari/iOS — «Поделиться → На экран „Домой“».

Локально: `python3 -m http.server` и открыть http://localhost:8000.
